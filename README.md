# KR Customizer Frontend

A responsive frontend web application built using React, Vite, and Tailwind CSS.

# Features

* Responsive Design (Mobile, Tablet, Desktop)
* React Router Navigation
* Login Page
* Register Page
* About Us Page
* Blog Page
* Contact Page
* Navbar & Footer
* Reusable Components

# Tech Stack
* React
* Vite
* Tailwind CSS
* React Router DOM

# Installation

```bash
npm install
npm run dev
```

# Build Project

```bash
npm run build
```
